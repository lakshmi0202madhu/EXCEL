# DELIVEROO SALES ANALYSIS
 A comprehensive Sales Analysis Dashboard for Deliveroo (Netherlands region). Using a dataset of over 5,000 orders, I transformed raw data into actionable business insights.

🛠️ The Workflow:

Data Exploration: Analyzed a complex dataset including order timestamps, customer demographics, delivery temperatures, and restaurant metrics.

Data Preprocessing: Used Power Query Editor to clean, transform, and format the data for a seamless analysis experience.

Visualization: Built dynamic Pivot Tables and unique visualizations—including Surface, Spider, and Pie charts—to track Revenue vs. Refunds.

Interactivity: Integrated Slicers (Gender, Subscription Type, Temperature, and Location) to allow for real-time data drilling.

💡 Key Business Insights:

Refund Patterns: Basic subscription holders showed a higher propensity for refund requests compared to premium tiers.

Environmental Factors: Delivery temperature significantly impacts the bottom line; refund amounts spiked during extreme "Warm" and "Cold" seasons.

Demographics: While revenue is balanced across genders globally, localized trends emerge when filtering by specific state codes.
